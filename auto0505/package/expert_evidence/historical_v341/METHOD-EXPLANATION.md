# 方法与证据说明

本任务优化 RF-Solver 的时间节点分配：在固定25个区间、每个方向50次网络调用、往返合计100 NFE的条件下，提高图像反演再重建的PSNR。FLUX权重、二阶积分器、图像尺寸和评分数据均冻结。`get_timesteps`允许实现整个节点生成算法；历史轨迹实际比较了密度函数、网格投影、节点预算交换等方法，优化面不限于预设标量搜索。

Starter 使用官方 FLUX logit 时间偏移。独立 Reference 使用正弦节点分配。本次同协议full16实测，Starter PSNR19.528882409499996，Reference20.45734928422148，提升0.928466874721483dB，Reference归一化reward0.46267401782591483。两次运行的资产、权重、评分器、环境和预算字段一致。没有训练环节，epoch、优化器和训练曲线不适用。

当前Public选中的Seed方法为反向幂律 `t_i=1-(i/25)^1.2`，共26个严格下降节点，从1到0，在高噪声端使用较小区间。原始方法代码SHA256为df41c5a4726df6debb31dd57abc38f1b9418dd20b085bdc7c15eece61a5e0805；选定文件保持原字节不改。代码注释中的误差密度解释属于启发式推测，当前证据证明的是该节点序列在固定评测下的重建改善。

两个历史候选已经在全新隔离环境、当前Task协议下各独立复测12张Public：Seed21.66197823479546，GPT21.21974298189495。正式04的新候选最佳20.65104213455171。按这些当前Public原始平均PSNR选择Seed，选定记录在full16前冻结；旧版本裁剪成1的分数未参与排名。full16是后续验收，不用于重新选方法。

选中的Seed方法随后通过独立full16，PSNR21.27548763952123、SSIM0.7167758922645703、reward0.8703690797499839。完整可信回执的资产、权重、评分器、环境、预算和GPU身份与NOP/Reference一致；Root逐项比较并重新计算归一化分数。相对NOP提升1.7466052300212347dB，相对Reference提升0.8181383552997517dB。
