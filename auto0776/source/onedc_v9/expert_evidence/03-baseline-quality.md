# Baseline 合理性检查（onedc-quant）

总评：**合理，通过**。

任务是冻结权重、熵模型、解码器和评测器后的测试时量化决策优化。Starter 与正式 Baseline 是同一份 naive dead-zone 量化器（τ=0.6）；Reference 只把量化决策替换为逐 latent 的 RDOQ（候选 q0±1，λ=0.055）。最终证据来自同一不可变 final-v8 镜像、同一 A10 GPU、同一 full-24 固定顺序评测器的九个全新评分进程。原始恢复包含 516 个文件并有独立 SHA256 回执；公开交付仅保留不含 Hidden 像素的聚合证据。

| 项目 | 状态 | 证据与判断 |
|---|---|---|
| B01 代表性 | 通过 | 优化面只有测试时量化规则。dead-zone 是均匀标量量化的朴素变体；τ=0.6 将码率放在任务目标工作点，适合作为不会预先包含 RDO 搜索的 Starter/Baseline。 |
| B02 实现与训练健全 | 通过 | 任务无训练。Baseline 实现短小、确定性，保持输入输出形状与 dtype；三次全新进程结果逐位一致。 |
| B03 公平预算 | 通过 | B/R/U 使用同一 final-v8 镜像、同一 checkpoint、同一熵模型、同一评测器、同一 full-24 顺序和单卡资源；每个角色均为三次独立评分进程。 |
| B04 配置与搜索公平 | 通过 | Baseline 的 τ 与 Reference 的 λ 选择过程在优化面和历史扫描材料中披露；正式比较只采用 final-v8 原生 Harbor 复测值。 |
| B05 随机性公平 | 不适用（确定性） | 无训练 seed。B/R/U 各三次独立进程的 DISTS 与 bpp 完全一致，样本标准差均为 0。 |
| B06 基本锚点 | 通过 | 官方方法复现已通过；final-v8 Baseline full DISTS=0.11711087326208751、bpp=0.0204925537109375，且作为评分 0 锚点实测返回 0。 |
| B07 改进归因 | 通过 | B→R 唯一方法变化是 dead-zone 到 RDOQ；权重、数据、熵模型、评测器与质量门保持一致。R full DISTS=0.11463754375775655，三次配对改善均为 0.00247332950433096。 |
| B08 选择披露 | 通过 | 最终 B/R/U、方法 SHA256、聚合指标、耗时、镜像摘要、协议及恢复包哈希均记录在 `optimization_evidence/native_calibration_v8/summary.json` 与 `comparison_summary.json`。旧 v7 与早期轨迹复核值已移出提交包，避免与最终锚点混用。 |

正式质量门为 public 与 hidden 的平均 bpp 分别不高于 Baseline 对应均值的 1.005 倍。九次 B/R/U 运行全部过门。最终 full-24 值如下：

|---|---:|---:|---:|---|
| Baseline | 0.11711087326208751 | 0.0204925537109375 | 0 | 完全一致 |
| Reference | 0.11463754375775655 | 0.020459493001302086 | 0.6243098009518612 | 完全一致 |
| Upper bound | 0.11314917107423146 | 0.02051628960503472 | 1 | 完全一致 |

Reference 分数 0.6243 位于要求的 0.15–0.80 区间；Baseline 方差为 0 且三次配对改善严格为正，因此改善可分辨性门通过。Hidden 图像本体与逐图私有结果不在公开提交包中，只保留聚合指标与可核验哈希。
