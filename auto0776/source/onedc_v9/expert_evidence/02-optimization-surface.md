## 1. 候选面最小实验结果（Kodak-24，冻结 λ4.6 权重，仅改编码端量化决策）

关键结构事实：**OneDC 解码端对 y 只做 `y_hat = y_q + means_hat`（y_q 为整数）**，因此编码端量化规则可自由改、解码端与码流格式零改动 —— 量化策略是天然可隔离的测试时优化面。

| 配置 | bpp | PSNR | MS-SSIM | LPIPS | DISTS |
|---|---|---|---|---|---|
| Baseline（官方 round） | 0.02447 | 22.301 | 0.7811 | 0.1534 | **0.0961** |
| RDOQ λ=0.02 | 0.02262 | 22.125 | 0.7731 | 0.1587 | 0.1016 |
| RDOQ λ=0.05 | 0.02083 | 21.910 | 0.7607 | 0.1700 | **0.1125** |
| dead-zone τ=0.6 | 0.02057 | 21.816 | 0.7529 | 0.1745 | 0.1175 |
| RDOQ λ=0.1 | 0.01884 | 21.516 | 0.7394 | 0.1947 | **0.1341** |
| dead-zone τ=0.7 | 0.01870 | 21.194 | 0.7208 | 0.2103 | 0.1490 |
| RDOQ λ=0.2 | 0.01633 | 20.789 | 0.6963 | 0.2491 | **0.1835** |
| dead-zone τ=0.8 | 0.01731 | 20.694 | 0.6891 | 0.2502 | 0.1875 |

相近 bpp 逐对比较（naive Starter vs 结构化方法）：

| 目标 bpp 档 | naive dead-zone DISTS | RDOQ DISTS | 改善 |
|---|---|---|---|
| ≈0.0207 | 0.1175 | 0.1125 | **−4.3%** |
| ≈0.0188 | 0.1490 | 0.1341 | **−10.0%** |
| ≈0.0168 | 0.1875 | 0.1835 | **−2.1%** |

解读：
1. naive dead-zone 不改变曲线位置，只沿 RD 曲线下滑（且被论文相邻 λ 档 dominate）——**合格的 naive Starter**。
2. per-latent RDOQ（用冻结熵模型 σ 做逐点失真-比特权衡）在全部三档上一致优于 dead-zone，改善幅度 >> 评测噪声（确定性评测，噪声=0）——**方法空间真实存在，且"更聪明的量化决策"确实能移动曲线**。
3. RDOQ 候选集目前仅 {q0−1, q0, q0+1}、失真代理为 latent MSE；扩展候选集、通道级步长联合优化、感知加权失真代理都是未探索的更大空间（→ U 的余量）。

## 2. 推荐面 A 评审表（selection-gates 全字段）

| 字段 | 内容 |
|---|---|
| **入口** | `src/modules/entropy/compression_model.py::process_with_mask()`（ŷ 量化决策点，eval 分支）；FSQ ẑ 固定 0.0034 bpp 不动 |
| **允许修改** | 仅测试时编码端量化/码率分配算法（量化规则、候选选择、逐通道步长、比特预算再分配）；评测脚本不得改 |
| **冻结面** | 全部预训练权重（一步 U-Net、codec、熵模型 σ、FSQ 码本）；解码端；熵编码器；评测协议（Kodak-24 + test_quality.py） |
| **B/R 算法差异** | B = 官方 uniform rounding + 全局 dead-zone 宽度匹配目标 bpp（naive 单旋钮）；R = per-latent RDOQ：逐 latent 在候选量化值上最小化 (q−x)² + λ·bits(q; σ̂)，σ̂ 为冻结高斯熵模型——决策是逐点、σ 自适应的，非全局旋钮 |
| **每 seed 原始分数** | 评测完全确定性（无采样、整数熵编码），单 seed 即真值；重复跑同一配置 bpp/DISTS 逐位一致（已验证：baseline 两窗口两次跑结果一致） |
| **方差/确定性说明** | 推理无随机性；唯一噪声源是评测指标自身的数值精度（<1e-6）。多 seed 不适用 |
| **质量门** | 目标 bpp 档（如 0.0207±2%）内 DISTS 改善 > 评测集间噪声（=0）即有效；归一化目标 [0.15, 0.8]；U = 独立实测最强结果（扩展候选集 RDOQ + 通道步长联合优化，待 authoring 阶段实测标定，**不取 R 自身**） |
| **运行成本** | Kodak-24 单配置：推理 ~45s + 评测 ~2.5min ≈ 3.5min；A100-40GB 占用 <12GB；双轨迹几十轮无压力 |
| **隔离风险** | 低。量化入口单一（process_with_mask），熵编码真实产出 bpp 防"估计比特"作弊；权重冻结由 checkpoint 只读加载保证；风险点=提交方可能调熵模型 σ 来压低估计比特——但 bpp 以真实 rANS 码流长度为准，此路封死 |
| **最终建议** | **GO 面 A**。任务形态：给定 λ4.6 冻结权重 + 目标 bpp 约束（建议 0.0207±2%，同时保留 0.0188 档做泛化检查），优化测试时量化决策使 DISTS 最低。备选面 B（语义注入/空间混合）、面 C（per-image latent 优化）保留，若 authoring 阶段 U−B 区间不足再切换 |

七门禁逐条：方法空间（✅ 量化/分配算法族，非调参）· 可隔离（✅ 单入口、解码零改动）· 可重算（✅ 确定性）· 公平 Baseline（✅ 官方 round + naive DZ，全预算）· 可辨改善（✅ R 已优于 B 4–10%，噪声=0）· 成本可控（✅ 3.5min/配置）· 可交付（✅ 复用上题 v3 评分器模式 + Harbor 打包）。

## 3. Baseline 合理性审查（baseline-quality B01–B08）

| 项 | 结论 |
|---|---|
| B01 代表性 | ✅ 官方 round 是论文原生量化器；naive DZ 是文献标准基线（JPEG 系），非人为弱化 |
| B02 实现/训练健全 | ✅ 官方权重 + 官方代码，复现偏差 ±1% 内；无训练环节（测试时面） |
| B03 公平预算 | ✅ B 与 R 同模型、同输入、同评测；B 的 DZ 宽度允许扫到目标 bpp（预算不劣于 R 的 λ 扫描） |
| B04 配置搜索公平 | ✅ B 的 DZ 扫描粒度（0.05 步长）不粗于 R 的 λ 扫描粒度 |
| B05 随机性公平 | ✅ 全程确定性，无 seed 维度 |
| B06 基本锚点 | ✅ 论文 Table 5 为外部锚点（±1% 复现）；bpp 以真实熵编码为准 |
| B07 改进归因 | ✅ R−B 差异仅来自量化决策函数（单文件单函数开关），归因干净 |
| B08 选择披露 | ✅ 评审表公开全部候选（DZ/RDOQ 全档位原始数据），非只报最佳点 |

## 4. 风险与退出条件

- 若 authoring 阶段实测 U−B 区间过小（R 已接近 U，归一化上限 <0.15 可达空间不足）→ 扩大 U 侧方法空间（候选集、通道步长、感知加权）仍不足则换面 B。
- 若发现 σ 熵模型在目标 bpp 档严重失配导致真实 bpp 偏离目标 ±2% 难以控制 → 放宽为「bpp ≤ 目标」惩罚式约束。
- 已知非问题：λ 多档换模型优于量化优化（论文曲线 dominate RDOQ 曲线）——**但题目约束为"给定单一冻结 checkpoint"**，换档不在允许空间内，需在题目描述中明示，避免被视为不公平约束。
