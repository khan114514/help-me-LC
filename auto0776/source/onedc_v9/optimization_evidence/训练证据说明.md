# 训练与优化证据说明

本任务不训练或微调模型。权重、熵模型、解码端和评测器保持冻结；可修改面只有 `/workspace/solution/method.py` 中的测试时量化决策。因此，`eval_replicate_1..3` 表示三个全新的独立评分进程，不是训练 seed。

正式比较使用 final-v8 不可变镜像 `sha256:40875d7a85a1923dbd2041239f7d1ffa367e20e95e1aa31546cfe2dffa08a2c5`，目标 Harbor 版本 0.23.0。每个进程按固定顺序评测 24 张图（public 16 后接 hidden 8），使用真实 rANS 码流 bpp；public 与 hidden 的平均 bpp 都必须不高于 Baseline 对应均值的 1.005 倍。

- Baseline：naive dead-zone，τ=0.6，方法 SHA256 `116ce1665e0cda66e0ac8d2ad0340929587ddb663528b68cd5b44df71628b198`。
- Reference：逐 latent RDOQ，候选 q0±1，λ=0.055，方法 SHA256 `48dbf1ef65c4a4ec8498160ca4d4943d32e082bb96bb4e3fb9c9b9fe95a26444`。
- Upper bound：门内可达的 per-channel RDOQ，方法 SHA256 `b3d03a7d2010b3e65e1c277f6c33e238f5f4abed68976afa978272e8c3473ef7`。

B/R/U 各运行三次，九次均有效、均通过码率门，同一角色的 DISTS 与 bpp 在三次运行中完全一致。聚合结果见 `native_calibration_v8/summary.json`；正式配对统计见 `comparison_summary.json`；B/R 每次运行的标准化 `result.json` 和聚合 `metrics.json` 分别位于 `baseline_runs/` 与 `reference_runs/`。

Reference 相对 Baseline 的 full DISTS 改善为 0.00247332950433096，归一化分数为 0.6243098009518612。它满足 0.15–0.80 的参考解范围。Baseline 的三次样本标准差为 0，且每个配对改善都严格为正。

早期 A100 pilot、v7 原生校准和旧轨迹复核不是最终评分证据。它们已从提交包移到私有恢复目录；保留的 `lambda_sweep/` 仅用于说明参数选择过程，不能替代 final-v8 的正式数值。

Hidden 图像、逐图私有指标和恢复归档不随公开包交付。公开包只保留聚合指标、方法哈希、镜像摘要和原始恢复包的 SHA256，供组织者按私有回执核验。
