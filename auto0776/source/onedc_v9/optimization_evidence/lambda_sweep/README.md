# Historical parameter sweep

These files record the pre-final parameter-selection sweep. They use an earlier hardware/evaluator snapshot and therefore do not define the submitted Baseline, Reference, Upper bound, bitrate caps, or normalized score.

The authoritative final-v8 results are:

- `../comparison_summary.json`
- `../native_calibration_v8/summary.json`
- `../baseline_runs/rep*/result.json`
- `../reference_runs/rep*/result.json`

The sweep is retained only to disclose which lambda values were examined and why the final Reference family was selected.
